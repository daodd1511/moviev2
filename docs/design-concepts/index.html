Flix — Redesign Concepts

Three candidate directions for the movie detail page. Same movie, same content — only the design changes. Open each in a browser tab and compare.

Concept A

Projection Room — dark cinematic, image-forward

The backdrop is the page. Teal-black ground derived from the brand color, one amber accent, hairline display type kept from today's look.

 Concept B

The Programme — light editorial, quiet chrome

A film-society programme sheet: ruled fact table, framed poster plate, teal as the single accent. The refined evolution of the current light look.

 Concept C

Midnight Marquee — bold expressive, poster-art

The detail page as a one-sheet: viewport-scale condensed type, cadmium-orange band, ticket-stub metadata, hard offset shadows.
