Three things to remember

Factory ≠ Host

GitHub builds, the server runs. The server never checks out code, never runs pnpm, never builds an image.

Pin the sha

Deploys reference an immutable sha tag. Rollback = redeploy any previous sha sitting in GHCR. latest is for humans.

Outbound only

The runner dials out to GitHub; nothing dials in. The public repo can't reach the server — it only leaves images + a note in the warehouse.
